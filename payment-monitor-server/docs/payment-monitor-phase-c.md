# 支付通知监控阶段 C 实施报告

实施日期：2026-07-17

## 1. 实现内容

- Android 升级至 `versionCode=2`、`versionName=1.1.0-dev`、`parserVersion=2`。
- 协议版本继续保持 1。
- Debug 增加原始通知采集模式：
  - 只采集微信、支付宝通知。
  - 解析前保存，因此可记录未命中通知。
  - 每个会话最多 1,000 条或 10 MiB。
  - 只写入 App 私有目录，不上传服务端。
- Release 使用空实现，不包含采集 Receiver、采集入口或文件写入实现。
- 增加 ADB 开始、停止、拉取、校验和脱敏脚本。
- 增加数据驱动解析回归样本。
- 金额解析拒绝长订单号，降低时间、版本、流水号和尾号权重。
- 微信店员/商业收款、支付宝店员通和商家收款证据使用更高优先级。
- 同一通知 key、postTime、方向和金额的内容更新不重复入库；金额或毫秒时间不同的事件仍独立保存。
- 服务端原文上传默认关闭，阶段 C 新事件 `raw_payload` 均为 `NULL`。
