# LuLuPay 码支付监控系统 - 管理后台前端

本仓库为 **LuLuPay 码支付监控系统** 的管理后台前端（Vue 3 + TypeScript + Element Plus + Vite），基于 [plus-ui](https://gitee.com/JavaLionLi/plus-ui)（RuoYi-Vue-Plus 官方前端）改造。

## 快速开始

```bash
# 安装依赖（需要 Node.js 20+ 与 pnpm 10）
pnpm install

# 开发模式（默认 http://localhost:5173，/dev-api 代理到后端 8080）
pnpm dev

# 生产构建
pnpm build:prod
```

环境变量说明见 `.env.development` / `.env.production.example`。
